Privacy

Last updated: November 2026

For kids: REAL does not ask for your real name, your email, or where you live. Your game is saved on your own device. Please don’t type your real name, address, school or phone number anywhere in the game.

The short version, for grown-ups

  • No accounts. No sign-up, no email, no passwords.
  • No ads, no tracking, no selling data. REAL has no analytics, no advertising and no third-party trackers.
  • Progress stays on the device. Saves, learning progress, words, notes, writing and the problem log are kept in the browser’s storage on this device.
  • You choose what to share. A save code, save file or teacher report code only leaves the device if someone copies or downloads it.

What is stored on the device

WhatWhy
The game save: the character’s game name, money, story progress, settingsTo keep your place in the game.
Learning progress: skills practised, right and wrong answers, a daily practice log (60 days)To adapt lessons, schedule reviews and show the Family view.
Words you tapped, notes, writing portfolio, conversation logSo the learner can look back at them.
A problem log (error messages only, no personal details)So a grown-up can copy it into a bug report if something breaks.

To delete all of it, clear this site’s data in the browser settings (or delete the installed app). A save file or code you made yourself stays wherever you put it.

When something leaves the device

FeatureWhat is sent, and to whom
Teacher report code (only if the student copies it)The nickname, class code and skill progress, to the teacher who receives the code. No real name or contact details.
Live neighbors (only when the game runs on claude.ai; off in School mode and switchable off in Settings)Anonymous presence only: animal type, jacket colour, position in the district and one of four preset gestures. No names, no chat, no trading.

Elsewhere, these features answer on the device instead.
🎤 Say it (only when the player taps the microphone)Speech is turned into text by the browser or device. Some devices do this on the device maker’s servers.
FontsText fonts load from Google Fonts, which sees the device’s internet address. The offline copy works without them.

Children’s privacy

REAL is designed for children and teens and is built so that the game itself does not collect personal information.
